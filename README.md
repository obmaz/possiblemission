# POSSIBLE MISSION (가능미션) — 네온 워크샵 미니게임 아케이드

5~100명 규모의 회사 워크샵, 팀 빌딩, 온보딩 행사에서 **로그인·설치 없이 링크 하나로 즉시 다 함께 즐길 수 있는 정적 웹 미니게임 아케이드**입니다.

---

## 주요 특징

- **제로 백엔드 · 100% 정적 웹 (GitHub Pages 즉시 배포)**: 빌드 과정 없는 순수 HTML5 / CSS3 / ES Modules (`./` 상대 경로 기반).
- **룸 시드(Room Seed) 동기화**: 진행자(MC)가 시드 코드(예: `MISSION-1`) 또는 공유 링크(`?seed=...&game=...`)를 전파하면, 5~100명이 모두 **동일한 문제·카드 배치·숫자/알파벳 시퀀스**로 공정하게 경쟁할 수 있습니다.
- **Slack / 카카오톡 원클릭 결과 공유**: 클리어 직후 S/A/B/C 랭크, 클리어 타임, 정확도, 시드 정보가 담긴 이모지 스코어카드를 1초 만에 복사합니다.
- **내장 Web Audio 신디사이저 + 16:9 아케이드 캐비닛**: 별도 오디오 파일 없이 경쾌한 아케이드 효과음을 실시간 합성합니다. PC/모니터(900px+)에서는 모든 미니게임이 **16:9 고정 프레임**에서 동일한 배치로 렌더링되고, 모바일(360px+)은 세로 플로우 레이아웃으로 자동 전환됩니다.
- **초보자 우선 UX**: 로비는 이름·룸 시드·게임 카드만 남기고, QR·MC 가이드 등 진행자 기능은 "진행자 도구" 팝오버로 정리했습니다. 게임 중 브라우저 뒤로가기는 항상 로비로 돌아옵니다.

## 미니게임 라인업

1. **틀린그림찾기 (`SPOT THE DIFFERENCE`)** — `js/games/spot-difference.js`
   - 보드게임 디저트 카페(20장 유사 일러스트 중 2장을 시드별로 조합)와 황혼의 모험 캠프 2개 테마 중 하나를 고르고, 난이도(쉬움 5곳 / 보통 7곳 / 어려움 9곳)를 골라 좌우 그림의 차이점을 찾는 게임.
2. **도블 스피드 매치 (`DOBBLE MATCH`)** — `js/games/dobble.js`
   - 두 원형 카드 사이에서 딱 하나 겹치는 같은 그림을 빠르게 찾아 터치하는 게임(사영평면 수학 기반, `EASY` 6개 / `MEDIUM` 8개(정식 도블) / `HARD` 10개 / `EXTREME` 12개 / `INSANE` 14개 / `GOD` 17개 아이콘, KRRI·KTX 심볼 포함, 회전·크기 변화 지원).
3. **플래시 암산 (`FLASH ANZAN`)** — `js/games/flash-anzan.js`
   - 숫자가 같은 자리에 하나씩 번쩍 나타났다 사라집니다. 머릿속으로 더해 합계를 입력하세요(키보드 또는 화면 키패드). EASY~GOD 프리셋이나 자릿수·숫자 개수·표시 간격·문제 수를 직접 정합니다. 같은 룸 시드면 모두 같은 숫자가 나옵니다.
4. **메모리 매치 (`MEMORY MATCH`)** — `js/games/memory-match.js`
   - `4x3`(6쌍), `4x4`(8쌍), `6x4`(12쌍) 3가지 템포, 2초 프리뷰, 연속 매칭 콤보. 카드 18종 중 6종은 철도 아이콘(고속열차·트램·철로·신호기·자기부상열차·열차 바퀴).
5. **숫자 숨바꼭질 (`NUMBER HIDE & SEEK`)** — `js/games/despair-fortress.js`
   - 후지큐 하이랜드 절망요새의 숨바꼭질 방을 옮긴 한 판짜리 게임. 벽 스크린 가득한 글자 타일 뒤에 3자리 숫자가 숨어 있습니다(같은 글자는 항상 같은 숫자). 처음엔 모든 숫자가 보이다가 몇 개씩 차례로 사라지고, 사라진 숫자는 가끔 다시 고개를 내밉니다. 찾을 숫자 3개 옆의 칸에 그 타일의 **글자 한 자**를 순서와 상관없이 입력하세요(칸을 고르고 타일을 눌러도 됨). 오답은 제한 시간 3초 감소. INSANE·GOD은 한글이 섞이고 흑백 회오리 배경이 돕니다.

## 로컬 실행 방법

ES Modules를 사용하므로 `file://` 직접 열기 대신 정적 서버로 실행해야 합니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://127.0.0.1:8080 접속
```

## GitHub Pages 배포 설정 방법

1. GitHub 저장소(`https://github.com/obmaz/possiblemission`) 페이지로 이동합니다.
2. 상단 탭 **Settings** → 좌측 메뉴 **Pages**를 클릭합니다.
3. **Build and deployment** 영역에서:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` / `/ (root)` 선택 후 **Save** 클릭
4. 약 1~2분 후 `https://obmaz.github.io/possiblemission/` 에서 바로 플레이할 수 있습니다. (루트에 `.nojekyll` 파일이 포함되어 있어 그대로 정적 서빙됩니다.)
